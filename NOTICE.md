## About the "Rigicon Live" name

The product name "Rigicon Live" was chosen by the author at the time this
software began being used together with colleagues at Rigicon Inc. The name
reflects that use context; ownership, authorship and all rights to the
software remain with Quantre34.

## About the Windows code-signing certificate

The Windows code-signing certificate embedded in the release binaries is
issued in the "Rigicon Inc." Subject Name. This is a build-artifact identity
kept stable so existing installations continue to validate updates without
having to re-trust a new certificate. It does not transfer any rights.
